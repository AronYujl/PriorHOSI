## 结论先行

**W3(`hand_object_contact_weight=3`)是选定的配置。** 在固定 299.52M 预算、统一推理引导
(`contact_weight=3` + `object_goal_weight=1`)下:

**这是 Phase 1B 第一个真正关闭接触缺口的训练侧干预**——推理期引导(P5 掩码、P6 子项权重、
U 格 GT 掩码)三连证伪后,缺口被证明属于训练侧几何,且训练损失里直接监督手物距离可以补上。

## 机制发现

1. **接触饱和极快**:0→1 接触 +0.083(最陡),1→3 +0.024,3→5 +0.009,5→8 +0.002,
   8→50 仅 +0.010。**几乎全部接触增益在 weight≤5 就被捕获。**
2. **运动代价近似线性**:mpjpe Δ 随权重线性增长(+0.28/0.57/0.78/0.88/1.15/1.42/2.50),
   无饱和。所以权重 >5 纯属浪费——用三倍 mpjpe 代价换 1.7% 接触增益。
3. **W15 反常**:接触 0.644 反而低于 W10 0.657、hand_pen 0.571 全场最差,不视为信号,
   疑似训练波动。
4. **预算因果链确认**(来自 P8 2×2):H0−L0 显示预算本身改善运动(−0.31 mpjpe),
   H1−L1 显示预算缓解几何项损伤(−1.55 mpjpe)。

## 教训

- **P8-H1 配置缺 `run_id`**,输出写到 `results/experiments/None/`,引发误判死锁、误杀、
  resume 的连环事故。**P9 全部臂显式设置 `run_id`**——这是 Phase 1B 最昂贵的一次配置失误
  (约 16h GPU 被误杀,靠 resume 挽回 75%)。
- 权重剂量-响应的价值:单点实验只能给"有效/无效",8 点曲线给出了**接触饱和 + 损伤线性**的
  完整形状,从而找到帕累托前沿。
