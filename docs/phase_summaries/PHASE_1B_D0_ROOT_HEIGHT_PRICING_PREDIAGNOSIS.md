## 1. D0 是什么的第零项诊断

被诊断的提案：给根竖直通道单独加一个绝对锚定损失项——在 `prediction[..., 1:2]`
（14 个被预测帧，与 `joint_position` 同一切片）上加一项，配一个标量
`root_height_weight`，默认 0.0 且为 0.0 时不进 `losses`/`total`（故与 P12 逐位相同）。
全文：`.claude/scratch/stagea_rootvert/STAGE_A_PROPOSAL.md`（scratch，未跟踪，
702 行，`PROGRESS.md` 记录 2026-08-21T01:40:59+08:00 写完）。

该提案的机制叙述是：**竖直偏置是目标函数对根高度定价不足**——唯一实质的地面锚定项
`fk` 只对 8 个远端关节打分、可被旋转补偿，而根竖直元素在 `joint_position` 里只占
该项对竖直偏移总价的 3.97%（`fk` 占 96.00%）。若机制成立，加价就应当收窄偏置。

提案自己写死了三个起训前的纯 CPU 证伪尝试（D0 数据分布 / D1 梯度份额 /
D2 打分-未打分关节偏置对比），**任一命中就不花那 25 h 训练**。D0 是第一个。

## 2. 判据在测量之前就冻结了

`STAGE_A_PROPOSAL.md` §9.1，原文（判据写在任何训练侧数字存在之前）：

> 在 `experiments/splits/omomo_hoi_train_validation_seed42.json` 的训练侧窗口上统计
> GT 骨盆高度均值，与测试侧 `0.874819 m` 比较。
> - **若训练均值 ∈ `[0.895, 0.918] m`（即接近模型落点 `0.906812`）→ 主因是分布位移，
>   本提案的机制叙述被证伪，abort，分类 `root-height-pricing-prediagnosis-negative-stop`。**
> - 若训练均值 ≈ 测试均值（`[0.865, 0.885] m`）→ 分布位移不是主因，提案继续。

这是 D0 唯一的判据，且它是**单侧可证伪**的：命中 abort 带就作废提案自己的机制叙述。

竖直轴的认定：`data/train/human_joints_aligned.npy` 为 y-up，竖直是 axis 1
（逐轴统计：axis 1 均值 0.873、std 0.086；另两轴 std 0.66 / 0.71）。

| 量 | 定义 | 值 |
|---|---|--:|
| **训练侧 GT** | 4,088 条 split 训练序列、764,710 帧，帧加权，骨盆 = 关节 0 | **`0.910245 m`** |
| 训练侧逐序列均值的均值 | 同上，序列加权 | `0.908182 m`（p5 `0.789968`、p50 `0.927095`、p95 `0.993877`） |
| 训练侧全量 | 全 4,304 条序列 | `0.910430 m` |
| 内部验证侧 | 216 条 split 内部验证序列、39,750 帧 | `0.913995 m` |
| **测试侧 GT** | `data/test/` 全 482 条序列、83,559 帧，帧加权 | **`0.872962 m`** |
| 测试侧 GT（协议子集） | 438×126 评测导出的骨盆竖直均值 | `0.874820 m` |
| **模型落点（D0 所用）** | 见 §3.1，是一个**复合量** | **`0.906812 m`** |

**三个主数字全部逐项复现**：`0.910245`、`0.872962` 精确重现；`0.906812` 在 §3.1 的

### 3.1 「模型落点 `0.906812 m`」是一个复合量，直接测得的骨盆值更高

复算时发现 D0 引用的这个数不是模型骨盆高度的直接均值，而是
**测试侧骨盆 GT 均值 + 全 24 关节的平均竖直偏置**：

```
0.874820 (GT 骨盆)  +  0.031993 (全 24 关节平均竖直偏置)  =  0.906813
```

直接测同一封存导出（`results/experiments/p1-hoi-p12-frame-repair-baseline-eval-guided-r1-s42-20260820/chois/`，
438 对 npz，`global_jpos` `(126,24,3)`，Z-up 竖直是 index 2）的**骨盆本身**：

| 量 | 值 |
|---|--:|
| GT 骨盆竖直均值 | `0.874820 m` |
| **模型骨盆竖直均值** | **`0.910926 m`** |
| 骨盆竖直偏置 | **`+0.036105 m`（+3.61 cm）** |
| 全 24 关节偏置（D0 用的那个） | `+0.031993 m`（+3.20 cm） |

**这处更正让 abort 更强，不是更弱。** D0 报的是「模型 − 训练 = `−0.003433 m`，
模型坐在训练均值的 3.4 mm 之内」；用骨盆自己的数是 `0.910926 − 0.910245 =`
**`+0.000681 m`**——模型骨盆坐在训练语料骨盆均值的 **0.68 mm** 之内。
判定与分类不变，结论方向不变，量级更极端。

## 4. 中止结论

**ABORT 带 `[0.895, 0.918]` 命中（`0.910245`）；CONTINUE 带 `[0.865, 0.885]` 未命中。**

结论：**那 +3.2 / +3.6 cm 的竖直偏置不是目标函数定价不足，而是 train/test 身高分布位移。**
训练受试（sub1–15）比测试受试（sub16–17）平均高 `+3.73 cm`，模型忠实复现了它被训练的
那个分布，落点与训练均值相差 0.68 mm。**加价只会让它更锐利地复现训练条件分布，
把测试集上的偏置放大，而不是收窄。** 提案的机制叙述被自己的第零项诊断证伪。

两条同向的支持性观察（来自提案 §9.1，从封存产物只读测得）：

- 逐受试：sub16（n=233）GT `0.892255 m`、偏置 `+0.025728 m`；sub17（n=205）
  GT `0.855005 m`、偏置 `+0.039112 m`。**更矮的受试被抬得更多**——sub17 矮 `0.037 m`、
  被多抬 `0.013 m`，约相当于 36% 的「完全回归到共同均值」。
- released InfBaGel 在同一测试集上也有 `+0.012718348 m` 的**同向**上偏。
  两个独立训练的模型同向偏，本身就是数据侧共同成分的证据。

成本：约 2 分钟 CPU，省掉一次约 25 h 的训练。这正是起训前证伪探针的用途。

## 5. D0 不建立什么

1. **不否证「竖直偏移支配 FID」这个测量。** 那是证据索引结论 21 的内容
   （一个刚体三数偏置向量值 1.142 / 1.054 FID，竖直分量 2.79 cm / 2.30 cm），
   D0 只否证「成因是定价不足」这一条**机制叙述**，被否的是补救方向而不是测量。
2. **不否证竖直偏置值得修。** 它把「怎么修」从「给已有项加价」改成「补条件信息」。
3. **不是模型成绩，不进任何对比表。** 它是数据侧统计加一次对封存导出的只读复算。
4. **不授权任何训练。** D1、D2 两项证伪探针在 abort 后未执行，也不再需要执行。
5. **不覆盖也不重开提案。** `STAGE_A_PROPOSAL.md` 留在 scratch 未跟踪、未提交、
   未分配 run id；它是一份被自己的第零项诊断作废的提案。

## 6. D0 内部有一次自我反转，后续测量证实了反转后的那一边

提案 §9.1 把「最强的单条论证」写成：第一个窗口的 2 帧历史是**真实 GT**
（`code/test_infbagel_hoi.py:717-726`），而 94.3% 的偏置就在第一个窗口内产生，
所以**信息够、只是目标函数没要求用**——即定价不足的形状。

**D0 的结论把这条反转了。** `code/priors/hoi/models.py:233-251` 的 forward 只收
`noisy`、`timesteps`、`text_embedding`、`object_bps`、`goals`、`progress`——
没有 betas，没有 `rest_human_offsets`。受试高度的唯一信息源就是那 2 帧历史，
而没有任何机制把高度从 2 帧携带到接下来的 14 帧。所以形状是**信息确实不够**，
不是「够但没被要求用」。

2026-08-22 的 Stage A 工作把这一条测得更准，并且更极端：**条件里根本没有高度目标。**
`pelvis_goal[1]` 在两处被显式清零——`code/datasets/infbagel.py:458` 与
`code/priors/hoi/diffusion.py:509`——而 `goals[3:6]` 是第二个恒为零的空槽。
见证据索引结论 23 的 2026-08-22 事后机制分析条目。

一条当时未解释、现在仍未解释的对照：released 权重在同一测试集上只偏 `+1.27 cm`，
比我们的 `+3.6 cm` 小。两个候选解释（它消费了形状信息；或它在更大的受试池上训练、
先验均值更低）都未被检验。**这条仍然是开放的**，且它直接决定「补条件信息」能拿回多少。
