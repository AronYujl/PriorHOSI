## 实现与协议

复用 `code/test_infbagel_hosi.py` 的 Hydra 入口，新增
`config_sample_hosi_multitask.yaml`。
`mixer.multitask` 处理来源索引、边界测量、任务契约和实际状态继承；
`mixer.multitask_geometry` 处理目标关系重建、体型转换、支撑位置、直线路径和原生网格检查。
核心契约、专家代码和训练参数保持原版本；本轮没有训练、专家采样或 Kimodo 重采样。

每段包含 `source_dataset`、`data_idx`、目标场景、起终点、文本、时长预算和接触要求。
语料来源场景与执行场景分别记录。每条边包含过渡动作、1.4 秒自由区间、前后各
0.3 秒上下文、物体策略和具体的目标上下文文件/字段/帧范围。
原 469 个任务及扩展链使用独立评测表；扩展链的所有过渡帧参与正式评测。

首段使用原始任务初态。后段接收前段及过渡实际达到的人体历史和物体变换。
Kimodo 可以使用发布的参照作为过渡目标；达到该状态后的专家继续从实际历史推理。
各段的 `data_idx` 始终保留来源语义，初态继承规则由任务清单明确指定。

构建固定使用原 67 个 TRUMANS 场景、未镜像的 LINGO v3 seed-42 test 来源。
文本类别明确限定为步行、坐到椅子/沙发及从座位起身；两个手部交互帧标记为 -1
本身无法排除刷牙、拿杯子等持物动作，因此还应用文本类别条件。
完整源序列终点与 HOSI 的任务参照帧分别保存。

第一版只尝试物体已低速、接近地面支撑且人体站稳的 HOI 参照。
固定四个坐下来源及一个步行来源，按原任务顺序检查场景；每场景最多一条，最多 12 条。
支撑搜索使用 0.1 米网格和八个朝向，先检查双侧臀部支撑、关节和步行路径，
再检查原生人体表面。直线路径长度限定 0.75–3 米，并包含持久物体的障碍几何。
同一 HOI 体型用于全链，站姿/坐姿上下文分别以常量竖直位移落地。

## 发布示例

原任务 `hosi-027`，场景 `0ab03928-28d4-4dfe-883e-63047de7cc9c`。
全链采用 OMOMO 来源的男性体型，`betas` 序列索引 416。

| 段 | 来源 `data_idx` | 新任务条件 |
|---|---:|---|
| HOI | OMOMO 1142 | 保留原任务：从 `(-0.88, 0.68)` 到人体目标 `(1.38, -3.46)`；三脚架目标为 `(0.905887, 0.518404, -3.783726)`。 |
| 步行 | LINGO 8487 | 从上述人体目标走到 `(0.723503, -2.470828)`，直线路径约 1.1872 米。 |
| 静态交互 | LINGO 900075 | 从步行目标移动并坐到低台阶；人体目标 XZ 为 `(-0.20, -2.40)`，场景目标高度为 0.527426 米。 |

表中人体二维坐标为世界 XZ，三维物体目标为 XYZ，单位米。
静态源文本为 `sit down on office chair`；场景核对确认目标是低台阶，因此发布文本为
`sit down on the low step`，并将原文本保存在 `source_text`。
这是任务语义标注，来源、几何、姿态及候选选择均保持原记录。

第一条过渡是 `release_and_walk`，目标上下文引用已验证的 HOI 末端参照；
第二条是 `align_for_sitting`，目标上下文引用已安放静态动作的前十帧。
两者均要求保持实际达到的物体状态，实际过渡前仍需检查这些上下文与该状态的几何关系。

| 参照检查 | 结果 |
|---|---:|
| HOI 人体最大场景 / 物体穿透 | 0 / 0 |
| 三脚架最低表面距地面 | 3.659 mm |
| 三脚架最大场景穿透 | 1.724 mm |
| 静态人体平均 / 最大场景穿透 | 0.0289 / 31.727 mm |
| 静态人体最大物体 / 地面穿透 | 0 / 0 |
| 两个支撑点的 SDF 距离 | −2.182 / −2.971 mm |
| 静态上下文脚部标记距地面最大值 | 39.046 mm |

静态参照最大穿透位于末帧右脚踝附近，通过的是本轮预设的最大 5 cm 几何容差。
双侧支撑点上方 4 cm 的 SDF 为正、下方 4 cm 为负，符合方向性的支撑检查。
这些结果支持发布输入 pilot；完整生成动作的接触、碰撞、滑步和连续性仍需评测。

## 失败与根因修正

首个 `p5-benchmark-multitask-inputs-s42-20260909` 运行保留为失败。
其零候选结果来自错误的输入构造：使用完整源序列末端及起终点路径朝向作为任务末端，
并对站姿/坐姿上下文施加同一个落地位移。全部原始输出和诊断均保留。

469 条任务的物体目标高度均匹配
`language.start_idx[data_idx] + 3 * test_frames[-1]`，当前原始偏移为 45 帧；
最大高度差 1.20e-7 米。该帧的人—物水平距离也逐条匹配，最大距离差 5.97e-7 米。
完整源序列末端的物体高度平均差 0.31838 米；沿用任务路径朝向时，水平目标关系平均差
0.33345 米。修正后用声明的窗口参照及给定目标关系推导末端朝向，469 条的三维物体
目标重建最大误差为 6.557e-7 米。

一个落地位移也无法同时使两个体型转换后的上下文接地。首个检查体型上的四个来源，
脚部距离最大值由 10.7–12.6 cm 变为分别落地后的 3.7–4.7 cm。
两个上下文各自的旋转及速度保持原值。修正保持来源、搜索预算和容差不变。
另保留一次诊断从错误工作目录启动的记录；原生 SMPL 路径需要 `code/` 工作目录。
